# How to run
1. Install ```requests```

    ```bash
    pip install requests
    ```

2. **Run the client** in a separate terminal:

   ```bash
   cd client
   python runner.py
   ```

   A full month is 30 nights of 100 plays. 
   It takes a few minutes to run. The nightly returns are printed and written to `nightly_returns.csv` for plotting.
